# Architecture

GhostGlass traces a command, normalizes the recording into structured
events, and serves those events to a local web viewer, a live stream, a
query engine, and portable exports. Everything runs on your machine.

## Pipeline

```
command
   ↓
strace -f
   ↓
line assembly
   ↓
split-syscall reconstruction
   ↓
normalization
   ↓
events.jsonl
   ↓
indexes
 ├─ replay
 ├─ live SSE
 ├─ query
 ├─ highlights
 ├─ cause chain
 ├─ diff
 └─ export
```

**command → `strace -f`.** The tracer backend spawns the command under
`strace -f -tt -T -y -yy`, following forks and recording syscall
start/resume lines with microsecond timestamps.

**Line assembly.** strace output is a byte stream; the parser assembles
complete lines, tolerating the kernel's line-buffering quirks.

**Split-syscall reconstruction.** Interrupted/resumed pairs
(`<unfinished ...>` / `<... resumed>`) are rejoined deterministically by
PID + syscall name into one canonical
`PID TIMESTAMP name(args) = ret` line. Unpairable fragments are dropped
and counted, never guessed.

**Normalization.** Each parsed syscall becomes a `GhostGlassEvent` with
a stable `sequence` number, `timestamp`, `type` (`process` | `file` |
`network`), `action`, and entity fields (pid, path, ip, port, …).

**`events.jsonl`.** The normalized event log, one JSON object per line,
appended as events are parsed. This is the source of truth; everything
downstream derives from it.

**Indexes.** On load, the store builds in-memory indexes (by pid, by
path, by type/action, by timestamp, by sequence) that power replay
seeking, the query engine, highlights, and cause chains.

## Components

**Tracer** (`src/tracer/`). Backend abstraction (`TracerBackend`:
`checkAvailable()` + `run()`), the strace implementation, exit-code and
signal handling, and the line-assembly parser. The parser, storage, and
CLI layers never see backend-specific output — a second backend would
plug in here.

**Parser** (`src/parser/`). `StraceStreamParser` handles one strace line
at a time and emits normalized events. `pendingSyscalls` tracks
unfinished syscalls per PID (bounded map); `syscallReconstructor`
rejoins resumed pairs. Works identically for batch traces and Live
Glass streaming.

**Storage** (`src/storage/`, `src/store/`). Runs live under
`.ghostglass/runs/<run-id>/`: `metadata.json`, `events.jsonl`,
`summary.json`, `highlights.json`, and the raw `trace.log`. The run store
provides the query/index API the viewer and CLI share.

**Viewer** (`web/src/`, served by `src/viewer/`). A dependency-free
TypeScript frontend: process/file/network graph, scrubbable timeline,
virtualized event stream, inspector, highlights panel, and the query bar.
The server is a small Node HTTP layer over the run store.

**Live Glass** (`src/live/`). `ghostglass watch` streams parsed events
to the browser over SSE while the command runs. The same parser feeds
both the live stream and the on-disk `events.jsonl`; when the command
exits, the live view transitions to full replay without a reload.

**Query engine** (`src/query/`). One deterministic parser + matcher +
index layer shared by the CLI, the saved viewer, Live Glass, portable
exports, and diff. The browser bundle uses a vendored copy
(`web/src/query/`, generated by `scripts/vendor-query-web.cjs` — never
hand-edit it; change `src/query/` and re-vendor). Supports structured
`key:value` filters, AND/OR semantics, timestamp and sequence ordering,
and `highlight:` filters over derived records.

**Highlights** (`src/highlights/`). Seven deterministic rules over the
event stream (burst detection, outside-cwd access, create-then-execute,
…). No AI, no DNS, no verdicts. Rules and thresholds are configurable
via `.ghostglassrc.json`.

**Cause chain** (`src/cause/`). Walks recorded process ancestry
(spawn/exec links, file/network ownership) from a target event back to
the root command. Confidence is `DIRECT`, `STRUCTURAL`, or
`INCOMPLETE`; missing links are labeled, never synthesized.

**Diff** (`src/diff/`). Compares two runs' summaries, processes (matched
by executable + argv + parent executable, not PID), files (by path),
network endpoints (by IP:port), and highlights. Computed on demand,
never persisted.

**Export** (`src/export/`). Embeds the run data and the viewer frontend
into one self-contained HTML file (or a JSON document). Redaction flags
are applied at export time; the saved trace is never modified.

## Data flow guarantees

- `events.jsonl` is append-only during a run; the store never rewrites history.
- Sequence numbers are assigned at ingestion and are stable for a run.
- Old traces (pre-sequence-number era) derive stable in-memory sequences
  from `events.jsonl` order and load, diff, and export cleanly.
- Reconstruction diagnostics (`reconstructed` / `unresolved` /
  `orphanResumed` / `mismatched`) are surfaced, not hidden.
